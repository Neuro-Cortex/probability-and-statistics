# 📊 Probability & Statistics Master Repository

Welcome to the **Probability & Statistics** repository! This project serves as a comprehensive collection of learning materials, notes, mathematical formulas, and practical code implementations for statistics and probability concepts.

---

## 📂 Repository Structure

```text
.
├── 01-descriptive-statistics/    # Mean, Median, Mode, Variance, SD
├── 02-probability-basics/        # Bayes Theorem, Conditional Prob, Combinatorics
├── 03-distributions/             # Normal, Binomial, Poisson, Exponential
├── 04-inferential-statistics/    # Hypothesis Testing, Z-test, T-test, ANOVA
├── 05-regression-analysis/       # Linear & Logistic Regression, Correlation
├── scripts/                      # Python/R code examples using NumPy, SciPy, Pandas
└── cheatsheet/                   # Quick reference formulas and summaries

```
